## ⚡ Overview
This is the personal portfolio of Aayush Mittal—full-stack developer and AI-native builder. The site is designed to stand out through its distinct **Neo-Brutalist Paper & Ink** aesthetic, high-fidelity custom motion sequences, and integration of interactive components.

The project was built using an **Agent-Driven Development Workflow**, relying on rigorous specs and parallel coding agents to deliver clean, slop-free component design.

---

## 🛠 Tech Stack
- **Core Framework**: React 19 & Vite 8
- **Motion & Timelines**: Anime.js v4 (Preloader vector draws) & GSAP v3 (ScrollTrigger parabolic scroll curves and page pinning)
- **Scroll Normalizer**: Lenis 1.3 (Smooth scrolling)
- **Styling**: Tailwind CSS & Custom CSS variables (Neo-Brutalist borders and offset hard-shadows)
- **Linting**: Oxlint (Static code analysis)

## 🚀 Getting Started

### 1. Installation
Install project dependencies using npm:
```bash
npm install
```

### 2. Development Server
Run the local Vite development server:
```bash
npm run dev
```

### 3. Build Production Bundle
Compile the optimized static production build into the `/dist` directory:
```bash
npm run build
```

### 4. Static Code Linter
Verify code quality using the ultra-fast Oxlint engine:
```bash
npm run lint
```
